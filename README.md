# SSL Code feedback

Problems reported from SSL Code land here. In SSL Code, click **Report a problem** on a thread or in the app. Your agent asks what you expected and what happened. It then files the report here under your own GitHub account.

**Reports are public.** That includes the issue, the screenshot and, for a problem in a chat, the full thread transcript, with secrets removed. They're stored on a `report/...` branch in your fork of this repo. You see everything before it's published, and nothing goes out until you approve it. Deleting your fork removes the attachments. The issue stays until we close or delete it.

You can also file by hand using the [issue form](../../issues/new/choose).
